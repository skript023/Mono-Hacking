# Equipment Slots UI Audit 001

Scope: native Unity inventory grid and ImGui equipment window.

## Findings

### 1. MEDIUM — Native grid has no visual grouping for custom slot types

`src/unity/equipment_slots.cpp:23,1293` clones the regular inventory grid and distinguishes the added slots mainly through short text labels such as `Util`, `Food`, `Ammo`, and `Q`. Empty space and identical vanilla cells do not separate equipment, consumables, and quick slots, so the new layout is difficult to scan.

Rules: R-05, R-31.

Suggested direction: keep the native inventory visual language, but group related slots and make each slot family recognizable without relying on abbreviated text alone.

### 2. MEDIUM — ImGui window presents the slot matrix as one dense block

`src/unity/equipment_slots.cpp:1538,1561,1564,1567` puts the toolbar, a long hotkey sentence, and a sparse 8×5 button grid into one fixed initial window. Empty cells create broad gaps, while occupied cells lose their type label until hovered; the categories therefore take extra effort to identify.

Rules: R-05, R-31.

Suggested direction: establish a clearer hierarchy between gear, utility, food/ammo/key, and quick slots, and make slot type and hotkey cues visible in the grid without depending on hover.
